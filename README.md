# martinzachariassen/homebrew-tap

Homebrew formulae for my projects.

```sh
brew install martinzachariassen/tap/<formula>
```

## Formulae

| Formula | Description |
| --- | --- |
| [`domeneshop-mcp`](https://github.com/martinzachariassen/domeneshop-mcp) | MCP server for the Domeneshop API |

```sh
brew install martinzachariassen/tap/domeneshop-mcp
```

Formulae are bumped automatically by each project's release workflow, which
opens a pull request here once the new version is published to npm.
